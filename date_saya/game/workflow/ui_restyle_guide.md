# UI Restyle Guide

Use this guide for UI assets instead of full generative redraw.

## Why

Your UI files are small and stateful:

- idle
- hover
- locked

If each state is separately regenerated by SDXL, shape drift and edge noise will make the interface inconsistent.

## Safe strategy

### Group A: large base panels

Examples:

- `UI menu base.png`
- `UI home base.png`
- `UI shop base.png`
- `UI map base.png`
- `UI mirror base.png`
- `UI name base.png`
- `UI gift base.png`

These can be passed through the background workflow at low denoise:

- denoise `0.22 - 0.32`
- IPAdapter weight `0.55 - 0.68`

Goal:

- cooler palette
- softer painted lighting
- less plastic-looking gradients

### Group B: buttons and icons

Examples:

- `UI button talk idle.png`
- `UI button talk hover.png`
- `UI button gift idle.png`
- `UI gift bear idle.png`
- `UI gift bear hover.png`

Do not regenerate these directly unless they are very large.

Instead:

1. Build one new visual direction from a large base panel.
2. Apply the same treatment to small assets in an editor:
3. Shift hue toward cool blue-violet / charcoal tones.
4. Lower saturation slightly.
5. Add a soft top highlight.
6. Add a subtle ink-like outline or darker edge accent.

## Prompt direction for UI studies

Use the preset in `ui_prompt_preset.txt` when testing large panel restyles.

## Recommended deliverable structure

Create output folders such as:

- `images_restyle/bg`
- `images_restyle/UI/base`
- `images_restyle/UI/manual`

Only replace production assets after checking alignment in-game.
